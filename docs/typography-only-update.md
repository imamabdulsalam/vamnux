# VAMNUX Typography-Only Update

**Updated:** 20 August 2026

The VAMNUX global text system now uses the rounded modern **Nunito Sans** family for storefront, User Dashboard, account-entry, policy, and Admin text surfaces. The update is constrained to typography declarations: no route, content, database record, authentication flow, catalog item, price, supplier operation, wallet action, payment action, or external social redirect was changed.

Desktop verification confirms that the storefront header, carousel, category navigation, catalog labels, product detail text, and protected User Dashboard render with the new family. The long authenticated display name remains contained in the existing Dashboard hero panel through a typography-only responsive size and wrapping rule; the panel, colors, controls, and account data remain unchanged.

Mobile verification confirms that storefront controls, hero copy, search field, category strip, and account navigation retain their existing responsive hierarchy with the new rounded family. The User Dashboard retains its pre-existing narrow-screen panel geometry as required by the typography-only constraint; no grid, padding, container, control, data, or navigation behavior was altered.
